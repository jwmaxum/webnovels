# 향후 개발계획 — 무료 웹소설·웹툰 서비스 출시와 고도화

기준일: 2026-10-10, 30단계. 이 문서는 후속 개발의 우선순위·필요 입력·완료 조건을 정한다.
31단계부터의 번호는 제안이며 단계 시작 시 실제 감사 결과와 `improveN.md`로 범위를 확정한다.

## 현재 완료와 출시 차단 사항

기존 작가 스튜디오에 저장/파일 가져오기·HWPX 변환·복구 접수, 관리자에게 고정 제출본
검토·감사·작가 피드백 경로가 있다. 30단계는 최신 검토와 실제 증거 파일을 고정하고
격리 데이터 복원에서 원본 행을 보존하는 [복구 후보 계획 도구](recovery-evidence-package-contract.md)를
추가했다. 전체 기능을 실제 운영에 인수한 상태는 아니다.

[읽기 전용 감사](../../artifacts/stage30-launch-readiness.json) 기준 Auth 42·연결 작가 30,
본문 충돌 78건·Storage 0, 기본 미적용 마이그레이션 12개와019/020 미적용, health503이다.
기존 검증 백업의 충돌은 소설 36·웹툰 42건이다. 실제 승인 자료·별도 복원 대상이 없어
출시 판정은 NO_GO다. 기능 구현과 데이터/권리/호스팅 인수 완료를 구분한다.

접근 가능한 운영 프로젝트 1개를 격리 대상으로 대신 쓰지 않는다. 비밀번호/토큰은 채팅·Git에
기록하지 않는다. 입력 부재 동안 도구 개발은 가능하지만 hosted/원본 승인 완료로 표시하지 않는다.

31단계의 SQL 후보 생성과32단계의 실제 적용/인수는 각각 완료 조건을 갖는다. 자료가 일부만
있으면 선택한 건만 검증하고 전체 출시 가능으로 계산하지 않는다. 매 단계는 관련 회귀·타입/
빌드·보안/diff 검증 후 커밋/push하고, CI/배포 결과와 실제 적용 여부를 함께 기록한다.

| 대상 | 다음에 확인할 사용 흐름 | 개발 판단 기준 |
|---|---|---|
| 웹소설 작가 | 첫 작품 생성→파일/직접 작성→미리보기→저장/예약→게시→수정 | 필수 항목과 게시 차단 사유가 명확하고 실제 저장 상태/충돌 복구가 보임; 새 초안과 기존 회차 교체를 명시적으로 구분 |

| 독자 | 작품 탐색/검색→회차 목록→읽기→이어읽기/선호→다음 회차 | 소설 글자/행간·웹툰 너비/로딩·읽던 위치·무료/유료 표시의 일관성, 느린 연결/접근성/계정 전환에서도 안전한 상태 |
| 관리자 | 검토·신고/이의·공개 제한·계정 연결·정산 | 메뉴별 실제 역할/감사/되돌리기와 책임이 분명하며 과거 캐시/CRUD로 서버 계약을 우회하지 않음 |

레진코믹스·문피아 비교는 기존 [서비스 개발 로드맵](development-roadmap-2026-10-08.md)을
기초로 실제 공개 화면/정책의 최신 상태를 확인하며 수행한다. 벤치마크 기능을 복제하기 전에
작가 작성/게시 완료율, 독자 이어읽기 성공률, 관리자 검토 소요 시간을 내부 베타에서 측정한다.
새 UI 도입은 성공 기준을 정하고 현재 UI와 비교해 결정한다. Next.js/Supabase 등 스택 제안은
현 코드·운영 계약과 이관 비용을 평가한 후 별도 결정하며 전면 교체를 출시 전제에 넣지 않는다.

## 운영·기술 정리

- 실패한 저장/업로드·예약 게시·검토/백업 작업을 관찰하는 로그와 재시도/수동 처리 절차를 인수한다. 알림은 담당자·중복 방지·보존 정책을 정한 후 연결한다.
- 백업의 실제 복원, 이미지 바이트 누락, 메일/cron 격리, 출시 되돌리기를 주기 운영 절차로 정한다. 이번 요청으로 예약 자동화를 생성하지 않는다.
- Author/Creator 별칭·영속 ID·IndexedDB 계정 매핑을 보존하고 과거 캐시 기반 통계/정산/댓글 경로는 서버 소유권 검증과 함께 개별 이관한다.
- CSP·인라인 스크립트·관리자 파일 다운로드·개인정보 로그·외부 링크 처리와 비밀 회전을 범위별로 확인한다. 새 기능 플래그는 실제 인수 전 기본 비활성이다.
- 신뢰할 수 있는 릴리스 회귀를 유지한다. lint 도입과 테스트 실행시간 정리는 별도 기술 과제로 삼고 합성 DB/VM 검증을 실제 브라우저 인수로 부르지 않는다.

## 서비스 오픈 완료 기준

모든 공개 대상의 실제 원본/권리·등급/AI 결정, 별도 hosted DB/Auth/Storage 복원과 역할 인수,
검토된 마이그레이션/P0 잠금·무료 공개본 이관, 실제 작가/독자/관리자 핵심 흐름, 새 snapshot과
되돌리기 증거, 해당 커밋의 CI/배포와 정상 런타임을 확인해야 GO로 전환한다.
현재는 코드30단계 완료와 서비스 출시 NO_GO를 별도로 보고한다.
