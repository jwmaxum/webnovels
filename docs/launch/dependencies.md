## 우선순위와 진행 가능 범위

- **SEC-R01(민감 열/비무료 본문 선택 수용)**은 출시 차단 항목이다. DEP-01/02를 해결해 실제 정책을 파악하고, 안전한 접근 제한부터 진행한다.
- 2단계 로컬 데이터 계약·마이그레이션 초안·격리 검증 설계는 바로 시작할 수 있다.
- 운영 DDL/RLS 변경·계정 재연결·잠금 SQL 적용은 DEP-01/02/04/05가 확인되기 전 완료 처리하지 않는다.
- 관리 토큰 실패를 서비스 키로 모든 테이블을 공개하는 방식으로 우회하지 않는다.
- 현재 노출 완화는 DB 권한이 필요하다. 페이지 버튼 숨김은 대응 완료가 아니다. 즉시 정책을 변경하지 못한 상태를 계속 명시하고 신규 원고 유입 확대를 보류한다.

## 초기 출시 범위 결정

이번 실행 기준은 무료 웹소설 작성·연재다. 신규 유료/성인/웹툰·후원·커머스는 비활성으로 계획한다. 기존 유료 권한·정산·계약·작품은 그대로 보존하고 데이터 조사 후 개별 지원/정책을 정한다. 첫 오픈에 수익 기능을 포함하는 방향으로 바뀌면 13단계를 출시 선행으로 바꾸고 인수 기준도 갱신한다.
