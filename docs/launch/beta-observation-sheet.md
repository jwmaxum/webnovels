# 제한 베타·운영 확인표 — 실행 전 양식

2026-09-24 현재 **베타 미실행**. 이 양식은 승인된 스테이징/베타 환경에서 실제 결과를 남기기 위한 것이며 로컬 mock 결과를 복사하지 않는다. 고객 원고나 비밀값 대신 시험 데이터 ID·해시·요청 ID를 사용한다.

베타 참여자는 작품/회차를 관리자가 대신 등록했는지, 막힌 단계와 소요 시간, 원고 손실/공개 오류 여부를 기록한다. 베타 시작·종료 시각, 대상 범위, 동의/공지 문구, 지원 채널, 관찰 담당, 중단 기준은 시작 전에 확정한다.

## 19단계 실행 준비 — 2026-10-09

베타는 **미실행**이다. [19단계 계약](stage19-quality-contract.md)과 [증거 예시](beta-evidence.example.json)를 사용한다. 환경/후보 전체 SHA·출시 범위·기간·지원 담당/시간·정책 동의·중단 기준을 확정하고 소설 작가 최소 5명·독자 30명, 웹툰 포함 시 웹툰 작가 최소 3명을 실제 참여자로 기록한다. 가상 계정과 자동 테스트를 표본에 포함하지 않는다.

추가 관찰: TOON-01~05 업로드/권한/가독성/위치/신고, 독자 페이지 필터·공개 회차 이동, 작가/관리자 지연 로딩 실패 재시도·경로 변경, 키보드 모달/IME/스크린리더, 운영 알림 수신·지원 복구를 위 표에 기록한다. 데이터 손실·권한 우회·잘못된 공개·중복 거래·P0 발생 시 베타를 중단하고 원본/요청 결과를 보존한다. 제한된 표본만으로 장기 유지율·구매 전환 성공을 선언하지 않는다.
