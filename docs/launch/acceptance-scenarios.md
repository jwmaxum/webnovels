# 출시 인수 시나리오 기준

작성일: 2026-09-23. **아래 시나리오는 정의 완료·실행 전**이다. 1단계의 정적 목록 검증과 서비스 인수 테스트 통과를 혼동하지 않는다.

공통 준비: 격리 DB/Storage, 익명·독자 A/B·작가 A/B·제한 관리자·최고 관리자·정지 계정. 조작에는 실제 고객 원고를 쓰지 않는다. 증거에는 요청 ID·상태 코드·시험용 원고 해시·화면 결과를 남기고 개인정보·원문은 넣지 않는다.

## 현재 상태

모든 서비스 시나리오는 미실행이다. 이번 단계에서 수행한 검사는 소스 목록 생성·문서 링크/ID/메뉴 커버리지 확인과 제한된 원격 HEAD/관리 접근 확인뿐이다. 브라우저·통합 테스트에 필요한 실행 조건은 [의존성](dependencies.md)을 따른다.
