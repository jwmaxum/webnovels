## 정책의 결정과 법령 근거

환불정책 v1.0 시행일은 2026-10-11이다. 유료 상품은 현재 미활성이며 해당 상품 판매 시
적용한다. 미사용 콘텐츠의 청약철회 기산일, 제공 개시 후 제한의 법정 고지/시험 이용 조건,
가분적 미제공 부분, 표시·광고/계약 불이행, 미성년자 취소, 과오금, 신청 서식과 접수 방법,
3영업일 환급·원결제 취소·지연배상·분쟁 처리를 작성했다. 내부 승인일을 법정 기산일로
바꾸거나 탈퇴를 이유로 거래 확인 가능한 정당한 환불을 일괄 거절하지 않는다.

회사의 추가 소비자 보호 기준으로 **미사용 유료 잔액의 별도 환불 수수료는 0원**으로
정했다. 실제 결제액/사용분을 기준으로 계산하며 불명확한 배분은 소비자에게 유리하게
처리한다. 이 공개 정책과 향후 유료 원장·부분 취소·지원 절차가 일치해야 한다. 포인트
소멸/정기결제/작가 지급 등 미확정 상품 조건을 현재 운영 사실처럼 기재하지 않았다.

참고한 공식 자료와 문피아의 약관 구조:

- [제13조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1024961577): 사업자 신원·신고 사항, 거래 조건과 청약철회/환급 절차의 사전 고지.
- [제17조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029561411), [제18조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022341869): 2026-07-21 시행본을 확인하고 기간·제공 개시·미제공 부분·환급 기산일과 원결제 취소를 반영.

이 문서와 페이지 게시가 통신판매업 신고 수리나 PG 심사 승인을 의미하지는 않는다.

## 유료 결제 개시 전에 남은 작업

1. 통신판매업 신고를 완료하고 발급받은 신고번호·신고기관을 홈과 세 공개 페이지에 동일하게 반영한다. PG가 요청하는 제출 자료·판매 도메인·실제 상품 정보도 확정한다.
2. 실제 개인정보 처리 항목·위탁/국외 이전·보유 기간과 담당자를 확인해 개인정보처리방침을 공개하고 가입/결제 화면에 연결한다. 업체나 보유 기간을 추정해 만들어 넣지 않는다.
3. 판매할 상품의 총가격·세금·제공 시점·이용기간·기술 환경, 미사용분 계산·무상/유료 분리·정기결제 여부를 확정한다. 구매 전 고지/미리보기와 약관·청약철회 제한의 필요한 동의 기록/버전을 서버에 보존한다.
4. [수익화 계약](monetization-contract.md)과 기존 TEST 전용 주문·원장을 확장해 실제 PG 승인/조회/웹훅·부분/전체 환불·실패 재시도·과오금/차지백을 검증한다. 공개한 무수수료·3영업일 기준과 실제 고객지원 처리 절차를 맞춘다.
5. 실제 역할·데이터·브라우저/기기 인수, 고객지원 접수·회신·원결제 취소 대사를 마친 후 유료 서비스 출시를 별도로 판단한다. 이번 작업은 결제/복구 플래그·DB·원고·원장을 활성화하거나 변경하지 않는다.

이 과제를 [향후 개발계획](future-development-plan-2026-10-10.md)의 유료 출시 선행 조건에
연결한다. 31단계 원고 복구 개발과 PG 심사 준비는 각각 완료 조건을 가진다.

## 검증과 Git 반영

새 런타임 로직·의존성·데이터 스키마를 추가하지 않는 정적 페이지 보완이다. 새 모사 테스트를
추가하지 않고, HTML 구조/링크/앵커·사업자정보·비밀/동적 코드 검사와 변경 범위의 기존
명칭/Auth/공개 runtime 회귀·Functions 번들·컴파일·타입/diff를 확인한다. lint는 미구성,
HTML/CSS 라인 커버리지는 해당하지 않는다. 브라우저/localhost 검증은 수행하지 않는다.
검증된 변경만 커밋/push하고 해당 커밋의 전체 CI·배포와 실제 HTTPS 페이지 상태/내용을
읽기 전용으로 확인한다. URL은 HTTP200과 정책 전문을 확인한 후 PG 제출 주소로 안내한다.
