# OP-04 회원 무료 회차·가격·열람권 TEST 구현

작성일: 2026-11-02 (Asia/Seoul) · 상태: **TEST 코드·전체 릴리스·타입·독립 리허설 검증 완료 / 운영 019·플래그 미적용**

[최소 운영 CMS 계획](admin-cms-minimal-ux-plan-2026-11-01.md)의 OP-04를 구현했다. 상세 입력·응답과 격리 기준은 [OP-04 공유 계약](op04-points-test-contract-2026-11-02.md)을 따른다. 회원 1~2화 무료, 이후 기본 100P와 회차별 열람권을 웹소설·웹툰에 함께 적용하는 **별도 TEST 경로**다. 기존 무료 베타 작품을 유료로 전환하거나 기존 잔액·권리를 시험 데이터로 바꾸지 않는다.

## 제공한 화면과 작업 흐름

| 화면 | 구현한 작업 |
| --- | --- |
| 관리자 `설정 → 서비스 정책` | 최고 관리자가 공개 적격 TEST 후보 검색, 직접 등록·노출 중단·재노출, 기본/작품/회차 가격 버전 설정, Auth UUID 대상 시험 지급 |
| 독자 `/reading-test` | 활성 독자 계정의 TEST 작품·회차·시험 잔액·이력, 회원 무료/보유/잠금 상태, 견적 확인과 명시적 구매, 현재 공개 소설 본문·인증된 웹툰 패널 |
| OFF 상태 | 준비 안내만 표시하며 TEST API를 호출하지 않음. 기존 무료 독자 화면과 실제 잔액을 변경하지 않음 |

상위 관리자 메뉴는 기존 6개를 유지한다. 가격 수정과 시험 지급은 **SUPER_ADMIN 전용**이며 추천 선정·작품 조회 권한으로 가격을 바꾸지 않는다. TEST 작품은 관리자가 명시적으로 등록해야 한다. 운영 작품을 자동 등록하거나 숨긴 작품을 다른 작품으로 대체하지 않는다.

독자는 50개 단위 작품·회차 목록에서 상태를 확인한다. 회원 무료 또는 보유 회차는 본문 확인으로 바로 이어진다. 잠긴 회차는 **가격 확인 → 포인트·만료 시각 확인 → TEST 동의 → 시험 열람권 받기**로 진행하며, 목록 조회·견적 발급·광고처럼 보이는 타이머만으로 차감하지 않는다. 시험 잔액이 부족하면 시험 지급 준비 상태를 안내한다. 아직 구현하지 않은 실제 충전·광고 성공을 표시하지 않는다.

양 화면은 `TEST / LOCAL_SIMULATED`와 실제 결제·충전 수납·작가 정산이 발생하지 않는다는 설명을 표시한다. 금액을 KRW로 환산하거나 `100P=100원`으로 가정하지 않는다. 작가 프로필 ID·작품 ID·이메일을 시험 지급 대상 Auth UUID와 혼용하지 않는다.

## 서버 판정과 가격·권리 계약

- 이메일 확인과 서버의 ACTIVE 독자 연결이 필요하다. 무료 범위는 **회차 번호 1·2**이며, 숨긴 회차를 제외한 목록의 첫 두 항목으로 다시 계산하지 않는다.
- 이후 기본 가격은 100P이고 **회차 예외 → 작품 예외 → 플랫폼 기본** 순서로 현재 시행 중인 가격을 고른다. 0~1,000,000 정수 P만 받으며 무료 2화 정책 자체는 이번 단계에서 고정한다.
- 가격은 UUID 버전·시행 시각·담당자·사유를 가진 불변 이력이다. 관리자 입력은 KST, 서버 저장·전달은 UTC이며 전역 revision CAS로 동시 수정을 막는다.
- 견적은 사용자·안정 회차 ID·현재 공개본·가격 버전·포인트·**5분 만료**를 서버에 고정한다. 구매에는 `quoteId`와 `requestId`만 받는다. 브라우저가 차감할 포인트나 소유자를 결정하지 않는다.
- 가격·공개본 변경, 견적 만료, 잔액 부족은 차감 없이 거절한다. UI는 확정 오류의 옛 견적을 폐기하고 명시적으로 다시 확인하게 한다.
- 지갑·요청·회차 잠금과 고유 제약을 사용해 시험 잔액 차감·소비 원장·구매·권리 발급을 한 트랜잭션으로 처리한다. 같은 요청의 재전송과 다른 탭의 이미 보유한 회차 구매는 추가 차감을 만들지 않는다.
- 열람권은 **안정적인 episode ID**에 연결한다. 가격이나 승인된 공개 head가 바뀌어도 같은 회차를 다시 구매하지 않는다. 거래에는 당시 가격·공개본을 남기되 실제 본문·패널은 항상 현재 공개 적격 head를 다시 확인한다.
- 최고 관리자의 시험 지급도 사유·고유 요청 ID·불변 CREDIT 원장으로 기록한다. 실제 입금 확인, 카드 승인, 작가 수익·지급 완료나 환불 처리가 아니다.

미확인 쓰기는 원래 내용과 요청 ID를 계정별 메모리에 유지하고 같은 요청으로만 결과를 확인한다. 이동 후 늦은 응답은 DOM에 반영하지 않으며 계정 변경·로그아웃은 사본을 폐기한다. localStorage에 잔액·권리·시험 거래를 저장하지 않는다. 현재 계정·권한 검증은 DB의 과거 영수증 재현보다 먼저 수행한다.

## 웹소설·웹툰 본문 보호

공개 적격 TEST 작품의 카드·회차 목록에는 본문·패널·Storage 주소를 넣지 않는다. 본문은 별도 `content`, 웹툰 이미지는 인증된 `panel` 바이너리 프록시로만 제공한다. 잠긴 회차는 `EPISODE_LOCKED`, 비공개·옛 head는 `CONTENT_NOT_AVAILABLE`로 거절한다. 유효한 구매 기록이 비공개·제재·권리 제한을 우회하지 않는다.

TEST가 활성화된 환경에서는 기존 무료 소설 본문·웹툰 이미지 경로를 **409 `POINTS_TEST_ROUTE_REQUIRED`**로 차단한다. 새 API 오류 뒤에 구형 무료 API로 fallback하지 않는다. OFF 환경은 기존 무료 동작을 유지한다.

소설은 기존 안전한 `ReaderContent`/`ManuscriptDocument` 렌더러로 Word 서식을 표시하며, 렌더러가 없으면 일반 텍스트만 표시한다. 임의 HTML을 실행하지 않는다. 웹툰은 기존 `ReaderWebtoon`의 가상화와 인증 load 콜백을 재사용하고, 미로드 시 이미지별 명시적 로드를 제공한다. PNG fallback도 같은 새 인증 API를 사용한다. 화면 이동·다시 그리기·계정 변경 시 이미지 object URL과 렌더러 자원을 회수한다. 시험 열람은 운영 독서 이력·조회수·성장 지표를 작성하지 않는다.

## 스키마와 환경 격리

[019 SQL](../../database/launch/019_points_test.sql)은 **미적용 추가 마이그레이션**이다. 이번 단계에서 합성 DB에만 적용하며 운영 DB·플래그·PG·PASS 설정을 변경하지 않는다.

새 구조는 `commerce.op04_*` 비공개 테이블 10개, 함수 8개, 불변 기록 트리거 6개이며 새 시퀀스는 없다. 테이블은 config·등록 작품·가격 정책·시험 지갑·견적·구매·권리·원장·영수증·감사로 구성된다. 초기 행 3개는 기본 config, 기본 100P 가격 정책, 마이그레이션 표식뿐이다. 시험 회원·작품 등록·시험 잔액·기존 금융자료 이관을 seed하지 않는다.

테이블 직접 접근은 anon/authenticated/service_role 모두 금지하고 RLS를 적용한다. 서비스 역할은 사용자·최고 관리자 권한을 다시 검증하는 RPC만 실행하며 비공개 보조 함수 EXECUTE도 회수한다. 새로운 public 테이블의 자동 권한에 의존하지 않는다. [명시적 권한 계약](supabase-explicit-grants-2026-10-21.md)과 기존 [Author/Creator 계약](author-creator-contract.md)을 유지한다.

서버 TEST 게이트는 다음 조건을 모두 요구한다.

1. `POINTS_TEST_ENABLED=true`
2. `POINTS_TEST_ENVIRONMENT=TEST`
3. `POINTS_TEST_PROVENANCE=LOCAL_SIMULATED`
4. `P0_API_ENABLED=true`
5. `FREE_BETA_ENABLED`가 `true`가 아님

기본 설정·LIVE·조건 누락은 닫힌 상태다. PG 키 없이 로컬 합성 시험이 가능하지만 실제 PG를 호출하지 않는다. 클라이언트에는 서버가 도출한 공개 boolean만 전달한다. 별도 환경의 스키마·계정·작품과 복원·권한·동시성 인수를 준비한 후 명시적으로 켜야 한다. TEST 원장은 기존 카드 KRW 원장·구형 포인트·P0 권리와 합산하지 않는다.

[독립 리허설](../../scripts/verify_op04_points_sandbox.mjs)은 새 합성 fixture에서 소설/웹툰 무료·잠금 목록, 명시적 구매와 재시도, 가격·head 변경 후 보유 회차 재열람, 인증 웹툰 패널과 타 계정 차단, 최종 지갑/원장 대조를 확인하도록 구성했다. `.env.local`·네트워크·운영 DB·제공자 없이 실행하며 결과는 Git 제외 `scratch/op04-sandbox/report.json`에 생성한다. 합성 검증 완료를 실제 서비스 전환으로 표시하지 않는다.

기존 구현과 fetch/PGlite/Node test/VM 도구를 재사용해 새 의존성을 추가하지 않았다. 저장소 소스와 [PostgreSQL 행 잠금](https://www.postgresql.org/docs/17/explicit-locking.html), [Supabase 함수 보안](https://supabase.com/docs/guides/database/functions) 공식 문서를 조사했다. 이번 요구에는 새 패키지가 필요하지 않아 npm 레지스트리·GitHub 패키지 검색은 수행하지 않았다. 그래프 연결/인덱스를 확보하지 못해 canonical 저장소의 관련 소스·기존 계약을 직접 확인했으며 그래프 탐색을 완료한 것으로 보고하지 않는다.

## 다음 OP-05

다음은 **충전상품·입금·카드 승인/환불·원거래 대사**다. 충전상품의 KRW 가격·지급 포인트와 회차의 소비 가격을 분리하고, 관리자 수동 입금은 실제 은행 거래 대조 후 한 번만 적립한다. 독자의 입금 신고나 결제 성공 복귀 URL만으로 지급하지 않는다.
