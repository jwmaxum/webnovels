# 운영 배포·공개 오픈 이슈 — 2026-09-25

**판정: NO GO.** [12단계 출시 기록](release-record.md)의 미완료 조건과 13단계 로컬 차단 작업을 합쳤다. 이 표의 담당은 역할 제안이며 실제 담당자·기한·승인자는 미정이다. 첫 오픈 범위는 [의존성 문서](dependencies.md)의 무료 연재 기준이다. 유료·성인을 포함하면 M01~M04도 첫 오픈 P0가 된다.

## 2026-09-25 후속 수정

- S01 진단을 분리했다. 공개/서버 프로젝트 키는 HTTP 200이지만 관리 PAT는 HTTP 401이다. 코드에서 새 PAT를 발급할 수 없으므로 계정 소유자가 교체해야 한다. **[교체·재검증·SQL·배포 실행 절차](production-activation.md)**에 위치와 명령을 기록했다.
- S04 일부 수정: 공개 API에서 성인·비무료·예약 회차 메타데이터를 제외하고, 브라우저 본문 조회가 API 거절 후 구 RPC/테이블로 우회하지 않도록 변경했다. 실 DB RLS/Storage 및 남은 직접 경로 감사는 미완료다.
- R02 일부 수정: `npm run build`가 전체 출시 회귀와 Functions 번들을 검증한 뒤 컴파일한다. 따라서 Pages가 문서의 build 명령을 사용하면 테스트 실패 시 빌드도 실패한다. 실제 Pages 설정과 배포 결과 확인은 별개다.
- R03 일부 수정: 서버 연결·기능 미활성 상태를 방문자에게 안내한다. 정적 자산은 캐시 재검증을 적용했다. 실제 기기·정책 문구 인수는 남아 있다.

## 실행 순서

1. 무료/수익화 첫 오픈 범위를 확정하고 기존 유료 권리·정산·성인 작품의 보호/지원 방침을 결정한다. 결정 전에는 신규 거래와 기능 플래그를 활성화하지 않는다.
2. S01~S04를 해결하고 [마이그레이션 절차](migration-runbook.md)에 따라 백업·격리 복원 후 스테이징 전환을 검증한다. 관리 감사 401이면 멈춘다.
3. R01~R05와 동일 커밋 CI/Pages 배포 차단 시험을 끝내고, 제한 베타 결과를 [관찰표](beta-observation-sheet.md)에 기록한다.
4. 담당자와 승인자가 실제 배포 ID·검증 계정·백업 ID·모니터링·공지를 [출시 기록](release-record.md)에 적고 공개 오픈을 별도로 판정한다.

운영 SQL·기능 플래그 변경·공개 오픈은 미실행이다. 코드 push 이후 CI/Pages 결과는 [출시 기록](release-record.md)과 해당 커밋 상태에서 확인한다. 로컬 테스트는 실환경 인수의 대체가 아니다.
