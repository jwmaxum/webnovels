# Localhost 및 브라우저 검증 규칙

1. **Localhost/브라우저 테스트 제한**:
   - `http://localhost:*` 접속, 브라우저 서브에이전트(`browser_subagent`) 실행 등 브라우저 기반의 로컬 동작 검증은 **사용자가 명시적으로 요청한 경우에만 수행**합니다.
   - 사용자의 명시적 요청이 없는 경우 임의로 브라우저를 열거나 Localhost 검증을 시작하지 않습니다.

2. **표준 검증 방식**:
   - 코드 구문 검사(`node -c`, `npx tsc --noEmit`) 및 정적 분석, 단위 테스트를 우선하여 빠르고 간결하게 결과를 도출합니다.
